# Minimal SQL Course

Hello, hey, hoi and welcome. This course aims to introduce you into the world of SQL querying and databases. The course will be covering databases (and what they are), SQL, and useful tools that you may find in your script kiddie carrer. Before we get lost in the weeds, let's talk about the benefits of this course, and other materials you can access to deepen your learning.

## Benefits
SQL is a foundational database querying language. There are other, less popular, developer only used alternatives, such as NoSQL. If you have a more non tehnical role, such as any of the following, you will probably have to trudge through with SQL:
